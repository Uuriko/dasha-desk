# Security policy

## Supported version

Only the latest commit on `main` is supported while Dasha Desk is in early alpha.

## Report privately

Use GitHub's **Report a vulnerability** flow at:

https://github.com/Uuriko/dasha-desk/security/advisories/new

If that flow is unavailable, open a public issue asking for a private contact channel **without including sensitive details**.

Useful reports include a wrong or substituted mint, hostile outbound URL, impersonation, unsafe clipboard behavior, injected content, or a third-party response that changes what the page links to.

Never send a seed phrase, private key, wallet export, access token, or funds. Dasha Desk has no wallet connection and will never need them to investigate a report.

There is currently no bug bounty or guaranteed response time.
