# Community code of conduct

## Our standard

Be curious, direct and respectful. Critique work rather than people. Welcome beginners, explain project constraints, credit other people's contributions and protect private or security-sensitive information.

Harassment, threats, discrimination, sexualized attention, doxxing, impersonation, spam, market manipulation and pressure to buy or promote a token are not acceptable here.

## Scope

This standard applies in repository issues, pull requests, reviews and other spaces represented as part of the Dasha Desk project. It does not make unrelated social accounts official project spaces.

## Reporting and enforcement

For an immediate public problem, use GitHub's report/block controls. For a private report, use **Security → Report a vulnerability** and state that it concerns conduct. Do not expose personal information in a public issue.

Maintainers may edit or remove content, close contributions, restrict participation or report conduct to GitHub. Decisions should be proportional, documented where safe and open to a good-faith request for reconsideration.
