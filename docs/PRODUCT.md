# Product: dasha desk

**dasha desk** is an open-source static mint desk for `$dasha` on Solana.

## Jobs

1. Mint she posted — hard to fake, easy to copy
2. Short quotes, not a whitepaper
3. Trade rails — Jupiter / chart / explorers
4. Paste checker for reply-guy CAs
5. Share pack for X

## Non-goals

Wallet connect, price predictions, backend, Demigod.

## Version

0.1 — single-file static app + config + MIT
