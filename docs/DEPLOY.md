# Deploy dasha desk

## Live

- **GitHub Pages:** https://uuriko.github.io/dasha-desk/
- **Repo:** https://github.com/Uuriko/dasha-desk

## Local

```bash
cd dasha-desk
python3 -m http.server 8766
```

## GitHub Pages

Deploy from branch `main` / root.

## Cloudflare Pages / Netlify

Connect `Uuriko/dasha-desk`, publish root, no build.

## Webflow

Paste `src/app.html` into HtmlEmbed (inline). Do not iframe catbox.
