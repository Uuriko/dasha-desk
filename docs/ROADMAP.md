# Roadmap

The Desk stays small. Work earns a place by making verification clearer, safer, or more reliable.

## Now

- keep the live Desk, generated builds, and mint config in sync
- improve keyboard, screen-reader, contrast, and reduced-motion behavior
- make public-data failures obvious without breaking the mint or source paths
- remove stale copy, links, and code

## Next, if proven useful

- show when independent public sources disagree
- remember a local-only snapshot and explain what changed since the last visit
- extract the mint checker into a reusable static component

Each starts as an issue with a small testable slice. None is promised.

## Resolved (maintainer work)

Tracked on GitHub so newcomers see the project moves. These are **not** external community PRs yet — when an outside PR merges, it will be listed here with credit.

- Demo GIF + README first-hour path
- CI verify + mint consistency gates
- Good first issues and Ideas template (#4, #7, #8 open or done as labeled)
- Neutral desk copy (no FOMO/raid framing)
- Contribute entry points via GitHub `/contribute` + site `#oss`
- Static **dasha bounties** board at `/bounties/` (GitHub issues as listings, no wallet, no escrow)

## Not now

- wallets, accounts, custody, or trading-terminal features
- price predictions, referrals, raids, or engagement farming
- a backend for behavior the browser can handle
- escrow, custody, or payout execution for listed bounties
- unrelated Studio or website features in this repository

See [CONTRIBUTING.md](../CONTRIBUTING.md) to propose or ship a change.
