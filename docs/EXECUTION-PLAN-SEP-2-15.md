## Outcome, Not Activity

By **September 15, 2026**, produce two defensible outcomes:

1. **OCM:** one reviewable, reproducible Apple-Silicon inference product with fresh final-head evidence and a truthful R[3]sidency application.
2. **Dasha:** one coherent Solana consumer project with durable project identity, a real mobile/wallet workstream, and a safe direct-settlement path that does not pretend to be escrow.

## Strategic Decision

For this period, **OCM is the primary founder/company narrative**. `$DASHA/getdasha.com` remains a separate Solana consumer/community project and public proof that John ships, but it is not OCM traction, OCM payment infrastructure, or OCM compensation.

Dasha work continues only where it unlocks identity, distribution, a bounded mobile milestone, or one honest settlement canary. Do not start another broad Dasha feature set, exchange campaign, game, social surface, or token incentive before these gates clear.

## Work-In-Progress Limits

At any moment, allow only:

- **one OCM core/release branch** — PR #76;
- **one OCM demand-side integration** — chosen from Cline, OpenRouter, Requesty, Portkey, LiteLLM, or Helicone after a response or a local smoke test;
- **one OCM external provider/runtime canary** — chosen from a responsive party, not five parallel adapters;

- **one token/listing identity action** — Jupiter VRFD first, then downstream wallets/listings;
- **one major application in drafting** — R[3]sidency before optional hackathons/grants.

A reply can enter the queue without creating an implementation project. Do not turn every positive email into code.
