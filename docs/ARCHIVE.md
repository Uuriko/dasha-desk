# The Dasha archive

What happened, when, and who made it. Contributed by anyone, including you.

## Why this exists

Communities that last keep records. Fan communities cohere around archives and wikis — the act of
documenting a thing is itself the act of belonging to it. Memecoin communities almost never build
one; they build group chats, which have no memory, and a year later nobody can say what happened or
who did the work.

This file is the cheapest possible version of that. No database, no accounts, no build step. One
file, edited by pull request.

## How to add an entry

You do not need to clone anything or install anything:

1. Open this file on GitHub and click the **pencil** icon.
2. Add your entry in date order.
3. **Propose changes** → **Create pull request**.

GitHub forks the repo for you. That is the whole process.

### Three rules

1. **Link a source.** A post, a transaction, a commit, an image — anything a stranger can check. An
   entry nobody can verify is a rumour with a date on it.
2. **Do not invent.** No approximated dates, no remembered numbers, no "around when". If you are not
   sure, write that you are not sure. An archive is only worth what its worst entry is worth.
3. **Credit people by the name they use.** If someone made a thing, say who. If they would rather not
   be named, that is their call and it outranks the record.

What does not belong here: price talk, predictions, returns, anything about who is up or down.
This is a record of what was made, not of what it was worth.

## Open questions the archive cannot answer yet

Honest gaps, left visible rather than papered over:

- **Who made the token, and when did the current project begin?** The pair dates to February 2025;
  the site and tools are from August 2026. What happened in between is not recorded anywhere we
  control.
- **Where did the name come from?** Recorded nowhere. Somebody knows.
- **The first meme.** Somebody made one before any of this existed. It is not in here.

If you can close one of these with a source, that is the most valuable pull request you could open.
