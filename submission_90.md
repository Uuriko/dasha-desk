# Dasha Commons × WURK: USDC Bounty Adapter Pilot – Implementation Plan & Script

## 1. Overview

This pilot connects Dasha Commons (PR #49 state machine) to WURK’s Solana microjob marketplace using a single real USDC bounty. The integration creates a bounty in Commons, mirrors it as a custom job in WURK, and settles the payout on-chain, with all records linked in a public receipt.

**Assets**: USDC (Solana) only.  
**Scope**: One bounded product‑testing task: “Test Dasha Commons PR #49 state machine – find and report a boundary case on devnet”.  
**Outcome**: A human‑readable receipt linking GitHub issue, WURK job ID, proof, selection, and Solana transaction.

---

## 2. Prerequisites

- A running Commons instance with PR #49 deployed (state machine: `create` → `fund` → `submit` → `select` → `pay`).
- WURK account with API key (or use the WURK UI for manual job creation if API is unavailable).
- Solana wallet (payer) with devnet USDC (get from a faucet).
- Node.js (v16+) and npm/yarn.
